# Independence Day Alien Signal — Pulse Reconstruction

Original reconstruction of the pulsing alien transmission sound associated with the observatory/laboratory scene in *Independence Day* (1996).

This repository contains an original synthesized reconstruction, oscilloscope data, and signal parameters. It is not the original film recording and does not contain sampled movie audio.

## Contents

- `audio/alien_pulse_closer_reconstruction.wav` — 7-second stereo WAV, 44.1 kHz, 16-bit PCM
- `oscilloscope/oscilloscope_signal_2khz.csv` — oscilloscope-ready amplitude data
- `oscilloscope/signal_parameters.json` — synthesis parameters
- `docs/README.md` — reconstruction notes
